## ⌨️ Control & Features / Управление и возможности
*   **Input / Ввод**: 
    *   `Alphabet` — Product names / Имя товара.
    *   `Digits` — Prices / Цена.
    *   `Left + Digit` — Set quantity / Ввод количества (стрелка Влево + цифра).
    *   `Tab`,`Right` — Auto / Автодополнение слова если есть в словаре.
*   **Fast Add / Быстрый ввод**: 
    *   Real-time suggestions. If there's one match and price > 0, press `Enter` to add.
    *   Подсказки на лету. Если совпадение одно и цена введена — `Enter` добавит товар.
*   **Analytics / Аналитика**: 
    *   `Up` / `Down` keys to browse historical weighted average prices.
    *   Клавиши `Вверх` / `Вниз` для просмотра аналитики. При желании можно эти файл `analitics.txt` самому бэкапить, ну сами догадаетесь у меня подход всё сделать через 3 файла.
*   **Exit & Sync / Выход и синхронизация**: 
    *   `Esc` — Calculate total and save files. Выход и вывод итоговой суммы, сохранение результата работы
    *    If `send.txt` exists, `reports.txt` is automatically sent to mail. Если в файл `send.txt` есть в директории и в нём код к ящику то результат работы с суммой улетит на почту.
## 📂 File Structure / Структура файлов
*   `products.txt` — Current shopping list.
*   `analitics.txt` — Cumulative price history.
*   `reports.txt` — Final report (sent via email).
*   `send.txt' — Send email (code data).

## 🛠 Build & Tech / Сборка и Оптимизация
Проект кроссплатформенный (Linux/Windows/MacOs).
