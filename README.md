## 📦 Что это такое

Это вещь, которая:
- Формирует словарь с текущими ценами как базу
- Позволяет составить список продуктов перед походом в магазин, чтобы прикинуть бюджет
- Считает сумму и при выходе сохраняет текущую покупку в `reports.txt`
- Если есть правильно заполненный `send.txt` — отправляет письмо на почту с этим списком

**Как это работает в моей семье:** я на работе, мне прилетает письмо — жена запустила программу, прикинула бюджет. По возвращению домой у меня есть этот список, и можно идти в магазин.

При последующем использовании программа сливает `reports.txt` и `analitics.txt` в один файл, получая средневзвешенные цены из истории. Строится аналитика, которая показывает тенденции. **Причём никто не заставляет нажимать Up — она всегда под рукой, хотите вы этого или нет.**

## 🌍 Global Language Support

Используется **UTF-8** — поддержка всех языков мира и кроссплатформенность. Всё проверено: без библиотек верно считает визуальную ширину символа и при письме справа налево (RTL) всё чётко в аналитике.

**Вам нужен просто терминал с ANSI-последовательностями.** Если у вас всё черно-белое — закомментируйте `USE_RGB` и включите `USE_BW` в исходниках.

**В интерфейсе нет ни одного национального символа** — в любой стране программа будет выглядеть как родная.

## ⌨️ Управление и возможности

### Ввод
- **Буквы** — имя товара
- **Цифры** — цена
- **`←` (влево) + цифра** — установка количества
- **`Tab`, `→` (вправо)** — автодополнение слова из словаря

### Быстрый ввод
- Подсказки на лету. Если совпадение одно и цена введена — `Enter` добавит товар.

### Аналитика
- **`↑` / `↓`** — просмотр исторических средневзвешенных цен
- Файл `analitics.txt` можно бэкапить самостоятельно

### Выход и синхронизация
- **`Esc`** — подсчёт итоговой суммы, сохранение результатов
- Если в директории есть `send.txt` (с кодом доступа) — результат с суммой улетит на почту

| Файл | Назначение |

| `products.txt` | Текущий список покупок |

## 🔐 О защите и HWID

Программа использует аппаратную привязку (HWID) для шифрования данных send.txt. Это значит:

- Ваши почтовые учётные данные не хранятся в открытом виде
- Файл с ключами нельзя просто скопировать на другой компьютер
- Расшифровка возможна только на том же оборудовании, где был создан файл

Это не "облачный сервис". Это ваш компьютер, ваши данные, ваша безопасность.

## 🛠 Сборка и оптимизация

Проект **кроссплатформенный**: Linux / Windows / macOS.

### Extreme Optimization
- **Бинарный файл при статической линковке с musl static занимает 57 КБ**
- Исполняемый код целиком помещается в **L1-кэш процессора** → максимальная скорость и мгновенный отклик
- **Чистый C11**

### Проверено на:
- **NixOS** — полёт нормальный (тут и писал)
- **Windows 10/11** — подправил `GetKey()` и `SetInputMode()` — заработало

**Главный момент:** теперь абсолютно всё равно, на чём вы сидите — Linux / Windows / macOS. Всё работает одинаково.
